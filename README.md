# Nerd Heaven — Desktop App

A desktop shell for **Nerd Heaven · The Tech Support Workshop**, Steven Powell's
offline IT-support course. The course itself lives in
[caeled/nerd-heaven-tech-support](https://github.com/caeled/nerd-heaven-tech-support)
(and at [caeled.neocities.org/learn](https://caeled.neocities.org/learn/));
this repo wraps the same files in a Tauri v2 window so the course can be
installed like a program and carried on a drive.

- Windows: NSIS setup `.exe` and `.msi` on the
  [releases page](https://github.com/caeled/nerd-heaven-app/releases).
- macOS: universal `.dmg` on the same page.
- Inside the app, the course stays in the window; documentation links and
  Discovery Room recordings open in your default browser. "Save progress to
  USB" and the workbook PDF download as usual.
